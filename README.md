# 🌦️ Weather App

A simple and responsive weather application that shows real-time weather information for any city using a public weather API.

---

## 🔍 Features

- 🌡️ Shows current temperature
- 🌤️ Displays weather condition (Clear, Cloudy, Rain, etc.)
- 💧 Humidity and wind speed information
- 🔎 Search weather by city name
- 📱 Responsive design (works on mobile & desktop)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Weather API (OpenWeatherMap or similar)
